# Domain docs

## Layout

This repo uses a **single-context** layout.

- `CONTEXT.md` at the repo root contains the current project context.
- `docs/adr/` contains architecture decision records, one per markdown file.

## Consumer rules

- Read `CONTEXT.md` before making large changes.
- When a decision changes or a new one is made, add or update an ADR in `docs/adr/`.
- Link new ADRs from the relevant `CONTEXT.md` section when applicable.
